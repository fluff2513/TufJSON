# TufJSON 🎨

> Too Useful For *JSON* - v1

A simple interactive Python script that formate a JSON file for your project.

## 🌴 Installation

```
git clone https://github.com/Fluff2513/TufJSON
cd TufJSON
pip install -r requirements.txt
python tufjson.py
```

## 🎀 Usage

```
python tufjson.py
```

Then just answer the questions - TufJSON does the rest!
